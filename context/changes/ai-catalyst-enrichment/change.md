# AI Catalyst Enrichment

Domknięcie luki: obecna analiza AI (`AiDivergenceService`, S-01) jest celowo
uziemiona wyłącznie w danych liczbowych — nie zna bieżących newsów ani wydarzeń
(„fresh catalysts"). Ten change ma dodać warstwę świeżych katalizatorów do
istniejącej, opłacanej integracji Claude API — bez crowdsourcingu i bez
publicznego callback API z idea_1.md.
